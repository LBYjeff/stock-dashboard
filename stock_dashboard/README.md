# 美台股看盤

## 🚀 啟動（iOS 介面版，主要版本）
1. 電腦需先安裝 Python 3.10 以上（安裝時勾選 *Add python.exe to PATH*）。
2. 解壓縮後雙擊 **`start.bat`**，會依序：安裝套件 → 每日更新（抓新資料、重新訓練模型）→ 開啟看盤。
3. 電腦開 http://localhost:8501；手機／平板連同一個 Wi-Fi，開視窗顯示的 `Network URL`，再「加入主畫面」。

- 經典桌面版（舊介面）：雙擊 `start_classic.bat`。
- Mac / Linux：`pip install -r requirements.txt && python update.py && streamlit run stock_app.py --server.address 0.0.0.0`

## ☁️ 雲端每日快照版（不需要電腦開著）
GitHub Actions 每天自動更新資料、重新訓練模型，產生 iOS 風格看盤網頁放在 GitHub Pages，手機加入主畫面即可使用。
設定步驟見 **`雲端設定說明.md`**（約 15 分鐘，只做一次）。
- 相關檔案：`.github/workflows/daily.yml`、`build_site.py`、`web/`、`requirements-cloud.txt`、`config.json`
- 網頁為唯讀快照；新增股票改 GitHub 上的 `config.json`，存檔後自動更新
- 每台裝置的清單與模型選擇記在該裝置上

## 📱 iOS 介面（遵循 Apple 人機介面指南）
- **四大導覽區域**（底部標籤列）：自選股／預測／檢討／設定
- **基礎視圖元件**：大標題導覽列、返回鍵、分組列表、列表儲存格、分段控制、卡片、標籤
- **設計規範**：系統字體與字級（大標題 34pt、內文 17pt、註腳 13pt）、iOS 系統色、深色模式自動切換、
  最小 44pt 觸控範圍、iPhone 安全區域
- 圖示為自繪線條圖示；顏色採台股慣例：紅漲綠跌

| 分頁 | 內容 |
|---|---|
| 自選股 | 報價、迷你走勢、5／20 日趨勢標籤；點進個股看 K 線、籌碼、高低點 |
| 預測 | 每檔 5／20 個交易日後的預估價與區間、三種模型比較、機器學習最看重的條件、技術型態訊號 |
| 檢討 | 回溯驗證／實際紀錄的命中率、每日成敗圖、失敗原因、初報告（可下載）、權重校正明細 |
| 設定 | 自選股清單（多組）、立即更新、預測模型選擇、FinMind Token、備份與還原 |

## 🧠 第二階段：個股機器學習（ml.py、pipeline.py）
- **每天自動更新**：補抓新資料 → 規則模型補算 → 重新校正權重 → 機器學習重新訓練 → 三模型比較 → 記錄今日預測
- **三種模型**：
  - 規則模型：10 張技術分析圖卡的型態規則
  - 校正模型：個股化權重與幅度係數
  - 機器學習：脊迴歸 ＋ 梯度提升決策樹（純 numpy），特徵含技術指標、大盤、法人、融資券、規則分數
- **前推驗證**：每 40 個交易日只用當時已知的資料重新訓練，產生完全沒看過答案的樣本外預測
- **自動選最佳**：每檔的 5 日、20 日各自採用最近 250 個交易日「落差 ≤ 5% 命中率」最高的模型（同分比 IC）
- 冠軍每天重新比較，會隨市場狀態改變；設定頁可改成固定使用某一個模型

## 💾 資料都存在本機
- `market.db`（SQLite）：日 K、大盤、法人、融資券、股利、各模型預測與實際紀錄，每天只補抓新的部分
- `config.json`：自選股清單；`calib.json`：權重校正結果
- 資料存在**執行程式的這台電腦**；手機、平板透過同一個 Wi-Fi 讀取，不上傳任何雲端
- **每台裝置用不同清單**：在「設定」建立多組清單，用那台裝置打開清單網址（`?wl=清單名稱`）後加入主畫面
- **換電腦**：設定 → 下載備份（zip），新電腦解壓程式後在設定 → 還原備份
- **不開畫面也累積資料**：把 `daily_update.bat` 加到 Windows「工作排程器」，每天收盤後（例如 15:00、06:00）執行

## 注意
- 日線資料，台股約 14:30 後、法人約 16:00 後、融資券約 21:30 後才是當日數據。
- FinMind 未登入每小時約 300 次查詢；自選股多時建議到 finmindtrade.com 免費註冊，把 Token 貼到側邊欄。
- 資料抓取有快取（報價 10 分鐘、法人/融資券 30 分鐘），要強制更新按側邊欄「重新抓取資料」。
- Yahoo 若抓不到台股，會自動改用 FinMind 的台股日 K。
- **休市日處理**：所有價格資料先依交易所日曆（台股 XTAI、美股 XNYS，含國定假日與春節）剔除休市日，成交量 0 且無波動的空白列（颱風假等臨時休市）也一併剔除；5 日／20 日預估日期只排交易日。

## 📱 手機版（mobile.py）
手機專用版面：單欄、卡片式數據、圖表不會吃掉手指滑動、台股/美股切換、自選股管理在最下方。
與桌面版共用自選股清單（config.json）。

### 方法 A：家裡 / 公司同一個 Wi-Fi（最簡單）
1. 電腦雙擊 `start_mobile.bat`，視窗會顯示 `Network URL: http://192.168.x.x:8502`。
2. 手機連同一個 Wi-Fi，用瀏覽器打開那個網址。
3. Safari「分享 → 加入主畫面」/ Chrome「⋮ → 加到主畫面」，之後就像 App 一樣一鍵開啟。
- 電腦要保持開機；第一次若跳出 Windows 防火牆，按「允許存取」。
- 公司網路常封鎖裝置互連，連不上時改用方法 B。

### 方法 B：放到 Streamlit Community Cloud（出門也能看，免費）
1. 註冊 GitHub，新增一個 repository，把整個資料夾上傳（可設為 Private）。
2. 到 share.streamlit.io 用 GitHub 登入 → Create app → 選該 repo，Main file 填 `mobile.py` → Deploy。
3. FinMind Token 不要放進 GitHub：在 App 的 Settings → Secrets 填 `FINMIND_TOKEN = "你的token"`。
4. 雲端版重開機後 config.json 會還原，常駐的自選股請直接改 repo 裡的 `config.json`。

## 🔮 趨勢預測（trend.py）
依 10 張技術分析圖卡的規則，自動辨識型態並打分，推估未來 5 個交易日與 20 個交易日的方向。

- **自選股表格**多兩欄「5日趨勢」「20日趨勢」：▲ 偏多 / ● 盤整觀望 / ▼ 偏空 ＋ 分數。
- **20 日預測**：K 棒、組合 K 線屬短線訊號只算 30% 權重，型態、均線、水平線全額計分；有同方向型態目標價時，路徑會往目標靠攏。
- **個股「趨勢預測」分頁**：K 線上自動畫出型態線（頸線、三角形/楔形上下緣）、水平支撐壓力、5 日預估虛線與區間色帶；
  列出每個觸發的訊號與分數，並附「這套規則在這檔股票過去 250 日的命中率」。
- 偵測項目：K 棒（大/中陽陰、十字線、長上下影）、組合 K 線（晨星、黃昏星、錘頭線、吞噬、黑三兵）、
  反轉型態（M頭、W底、頭肩頂/底、三重頂/底、倒V、菱形頂）、整理型態（上升/下降三角形、三角收斂、擴散三角形、
  箱型、上升/下降楔形、上升/下跌旗形、通道）、水平線（碰觸 ≥2 次的價位）、均線黃金/死亡交叉與排列。
- 圖卡之間有互相矛盾處，採用一般技術分析的通用定義：上升楔形＝偏空、下降楔形＝偏多；
  旗形看「旗桿」方向（急漲後整理＝上升旗形、急跌後整理＝下跌旗形）。
- ⚠️ 規則式評分，不是保證，也不構成投資建議。先看回測命中率有沒有高於「任意持有上漲機率」，再決定要不要參考。

## 📋 預測檢討（evaluate.py、predlog.py）
個股頁面的「📋 預測檢討」分頁（手機版為「檢討」）：

- **成功判定**（兩種同時顯示）：
  - 固定 5%：|實際收盤 ÷ 預估價 − 1| ≤ 5%
  - 預測區間：實際收盤落在依個股波動調整的預估區間內
  - 對照組「股價不動」：假設 N 日後價格不變的命中率；模型要高於它才有價值
- **資料來源**（可切換）：
  - 回溯模擬：用過去 500 個交易日「當天以前看得到的資料」重跑預測，馬上有成績
  - 實際紀錄：每天打開看盤時自動把當天預測存進 `predictions.db`，5／20 個交易日後自動對答案；
    過去的紀錄不會被改寫，是沒有事後偏誤的真實成績
- **失敗原因**（落差 > 5%）自動歸類：除權息、大盤連動、跳空缺口、法人反向、爆量、型態失效、
  盤整誤判、方向錯誤、幅度低估，並附每筆細節
- **初報告**：成績、失敗原因解讀與建議、個股化邏輯，可下載 HTML；每日預測紀錄可下載 CSV
- **個股化預測邏輯**（存在 `calib.json`）：
  - 用前 60% 期間找出各類訊號的最佳權重倍數（0～2 倍），並用最小平方法調整「預估幅度係數」
  - 用後 40% 期間驗證：落差≤5% 命中率提高、且 IC 與方向命中率都沒變差，才標記為「採用」
  - 側邊欄（手機版在「管理自選股」）「套用個股校正權重」可切換
- 第一次打開某檔的檢討分頁需要 5～15 秒計算，之後 6 小時內使用快取；按「重新檢討這檔」可重算
- 雲端部署時 `predictions.db`、`calib.json` 會在重新啟動後清空，長期累積實際紀錄建議在自己電腦執行
