# 雲端每日快照版：設定步驟（約 15 分鐘，只做一次）

設定完成後，GitHub 每天會在雲端自動：抓新資料 → 重新訓練模型 → 產生看盤網頁。
手機、平板、電腦打開同一個網址就能看，**不需要你的電腦開著**。

> 自動更新時間（台灣時間）：週一～五 16:30（台股收盤、三大法人公布後）、週二～六 06:30（美股收盤後）。
> GitHub 的排程偶爾會延遲幾分鐘到數十分鐘，屬正常現象。

---

## 步驟 1：註冊 GitHub
到 https://github.com 免費註冊帳號（已有帳號可跳過）。

## 步驟 2：建立儲存庫（Repository）
1. 右上角「＋」→「New repository」。
2. Repository name 填 `stock-dashboard`（可自訂）。
3. 選 **Public**（免費帳號的 GitHub Pages 網頁需要 Public；內容只有股價與預測）。
4. 按「Create repository」。

## 步驟 3：上傳程式
1. 在新的儲存庫頁面點「uploading an existing file」。
2. 打開解壓縮後的 `stock_dashboard` 資料夾，**把裡面所有檔案和資料夾一起拖進網頁**
   （包含 `.github`、`web` 資料夾；用 Chrome 或 Edge 拖曳資料夾最順）。
3. 下方按「Commit changes」。
4. 確認儲存庫裡有 `.github/workflows/daily.yml`。
   如果沒有（有些瀏覽器不會上傳 `.` 開頭的資料夾）：
   「Add file」→「Create new file」，檔名輸入 `.github/workflows/daily.yml`，
   把電腦上同名檔案的內容整份貼上，按「Commit changes」。

## 步驟 4：開啟 GitHub Pages
「Settings」→ 左側「Pages」→ Source 選 **GitHub Actions**。

## 步驟 5（選填）：FinMind Token
台股法人、融資券資料來自 FinMind，不填也能用。若自選股很多，建議到 https://finmindtrade.com 免費註冊取得 Token：
「Settings」→「Secrets and variables」→「Actions」→「New repository secret」，
Name 填 `FINMIND_TOKEN`，Secret 貼上 Token。

## 步驟 6：第一次執行
1. 上方「Actions」分頁（若出現提示，按綠色按鈕啟用 workflows）。
2. 左側點「每日更新看盤」→ 右側「Run workflow」→「Run workflow」。
3. 第一次要建立資料庫並訓練模型，約 5～20 分鐘（股票越多越久）。出現綠色勾勾就完成。

## 步驟 7：在手機打開
網址是：`https://你的帳號.github.io/stock-dashboard/`
（也可以在「Settings」→「Pages」看到完整網址）
- **iPhone／iPad**：Safari 打開 → 分享按鈕 →「加入主畫面」。
- **Android**：Chrome 打開 →「⋮」→「加到主畫面」。
之後從主畫面點開就像 App。

## 日常使用

**新增／移除股票、建立多組清單**
在 GitHub 打開 `config.json` → 右上鉛筆圖示編輯 → 「Commit changes」。
存檔後會自動更新，約 5～15 分鐘後網頁就會出現新股票。
```json
{
  "watchlists": {
    "我的自選": ["2330", "2454", "0050", "NVDA", "TSM", "AAPL"],
    "手機": ["2330", "0050", "NVDA"]
  }
}
```
台股填數字代號，美股填英文代號。看盤的「設定」分頁也有直接連到這裡的捷徑。

**每台裝置用不同清單**：在看盤「設定」分頁點選清單，選擇會記在那台裝置上，互不影響。

**想立刻更新**：看盤「設定」→「立即更新」→ GitHub 頁面按「Run workflow」。

## 常見問題

- **某天沒更新**：到「Actions」看是否有紅色 ✗。Yahoo 偶爾會擋雲端連線，按「Re-run jobs」重跑通常就好。
- **GitHub 寄信說排程被停用**：公開儲存庫長時間沒有活動時，GitHub 可能暫停排程；
  到「Actions」→「每日更新看盤」按「Enable workflow」即可恢復。
- **費用**：公開儲存庫的 Actions 與 Pages 都免費。
- **資料存在哪**：資料庫 `market.db` 存在儲存庫的 `data` 分支，每天只保留最新一份，不會越來越大。
- **想同時在自己電腦用完整互動版**：照 README 用 `start.bat` 即可，兩者互不影響。
